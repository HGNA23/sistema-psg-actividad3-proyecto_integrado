### Descripción del Repositorio
Este repositorio contiene los entregables oficiales correspondientes a la **Actividad 3: Validación y presentación final del proyecto** del sistema de información para cotizaciones e inventario de la microempresa **PSG (Persianas, Soportes y Blackouts)**.

### Estructura de Archivos
* `Actividad_3_Validacion_Presentacion_PSG.docx`: Documento formal con el informe de validación, observaciones, mejoras, requisitos funcionales y conclusiones.
* `index.html`: Prototipo web interactivo funcional que implementa el flujo comercial, control de inventarios, alertas de stock mínimo y seguimiento de servicios con acceso por roles.
* `README.md`: Este archivo de documentación del repositorio.

### Instrucciones de Ejecución del Prototipo
1. Descargue o clone este repositorio.
2. Abra el archivo `index.html` directamente en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
3. Seleccione el rol de acceso deseado (Administrador, Asesor Comercial o Técnico Instalador) e ingrese al sistema para probar las funcionalidades en vivo.
